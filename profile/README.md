# GC Cloud One: Aurora

Welcome to the **GC Cloud One: Aurora** GitHub organization.

## General

- **[gccloudone](https://github.com/gccloudone)**: Public-facing content and documentation, including the Aurora documentation site.

## Aurora

- **[gccloudone-aurora](https://github.com/gccloudone-aurora)**: Platform tooling, Helm charts, Kubernetes manifests, custom controllers, and the `project-*` configuration repositories that drive GitOps reconciliation.
- **[gccloudone-aurora-iac](https://github.com/gccloudone-aurora-iac)**: Terraform Infrastructure-as-Code modules used to provision the Azure resources that Aurora depends on.
- **[ssc-aurora](https://dev.azure.com/SSC-Aurora)**: Azure DevOps Organization where you can find the pipelines for deployment of Enterprise Scale Landing Zones (ESLZ)
